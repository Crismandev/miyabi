💡 Nota sobre apertura de archivos locales (file://):
Los navegadores bloquean la ejecución de scripts remotos cuando un archivo HTML se abre directamente haciendo doble clic (debido a la política de origen de seguridad file://).
Para ver el diagrama renderizado en el navegador:
  1. Ejecuta un servidor HTTP local desde la terminal en la raíz del proyecto: python3 -m http.server 8000
  2. Abre en tu navegador: http://localhost:8000/docs/diagrams/viewer.html
  3. O abre directamente el archivo er_diagram.md en la vista previa de Markdown de VS Code / Antigravity IDE (se renderiza automáticamente).

    room_type {
        int type_id PK
        string name_type UNIQUE
        text description
        int capacity_people
        decimal base_price
        decimal high_season_price
        string image_url
        string floor_plan_url
        json amenities
    }
    room_images {
        int image_id PK
        string image_url
        tinyint is_main
        int type_id FK
    }
    rooms {
        int room_id PK
        string room_number UNIQUE
        int floor

        int type_id FK
    }
